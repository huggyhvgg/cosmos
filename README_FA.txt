COSMOS ULTIMATE - نسخه قابل نصب روی اندروید (PWA)

روش راه‌اندازی:
1) پوشه را به صورت ZIP در Netlify Drop یا یک میزبان HTTPS سازگار منتشر کن.
2) آدرس HTTPS سایت را در Chrome اندروید باز کن.
3) از منوی سه‌نقطه Chrome گزینه Install app یا Add to Home screen را بزن.
4) آیکون COSMOS روی صفحه اصلی گوشی ظاهر می‌شود.

نکته:
- این بسته APK نیست؛ یک وب‌اپلیکیشن قابل نصب (PWA) است.
- برای نصب PWA باید سایت روی HTTPS میزبانی شود؛ بازکردن index.html مستقیم از فایل‌منیجر کافی نیست.
- بخش‌هایی که به اینترنت و APIهای بیرونی نیاز دارند، همچنان به اینترنت وابسته‌اند.
